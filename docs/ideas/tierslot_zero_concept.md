# ティアスロ・ゼロ 仕様メモ

> **区分：新作構想／アイデア段階**  
> TierSlot β・TierSlot2の既存仕様とは別企画として保管。記載のない仕様は補完しない。

## コンセプト

- スロットをビルドして遊ぶ**ハクスラ×ローグライト**。
- ヴァンサバのように毎回レベル1からスタート。
- キャラクターではなく、**スロットそのもの**を育成・改造する。

## ビルドシステム

- スロットの基板＝スキルツリー。
- チップを装着して能力を強化（グリフのような役割）。
- スキルは最大6枠。
- 基本スキル・奥義スキルをセット可能。
- クールダウンは時間ではなく**ロール数**で管理。

## ドロップ

- チップは敵や報酬からドロップ。
- レアリティ（原文の順序）：
  1. ミシック
  2. ユニーク
  3. レジェンダリー
  4. レア
  5. マジック
  6. ノーマル

## チップコスト

ビルドの**総コスト100**。

| レアリティ | コスト |
|---|---:|
| ミシック | 100 |
| ユニーク | 50 |
| レジェンダリー | 25 |
| レア | 10 |
| マジック | 5 |
| ノーマル | 1 |

## 開始時のビルドモデル

- ミシックモデル
- ユニーク2枚モデル
- ユニーク1枚＋レジェンダリー2枚モデル
- レジェンダリー4枚モデル
- カスタムモデル

## 設計思想

- カスタムモデルが最強という設計にはしない。
- モデルごとに「得られる気持ちよさ」が異なる。
- ミシックモデル：直感的で派手な爽快感。
- カスタムモデル：細かなビルド研究を楽しむ。
- **「強さ」ではなく「遊び方」を選ぶゲーム**を目指す。

## 敵システム

敵には**ユニットコスト**の概念がある。

| 敵の種類 | ユニットコスト（例） |
|---|---:|
| 雑魚 | 1 |
| エリート | 10 |
| 中ボス | 20 |

- ウェーブごとに総コストが**ぴったり**になるようランダム生成。
- 毎回異なる敵編成になる。

## ウェーブ構成

- 通常ウェーブを進行。
- 5ウェーブまたは10ウェーブごとにボス戦。
- ボス撃破後に報酬を獲得し、さらにビルドを強化。
