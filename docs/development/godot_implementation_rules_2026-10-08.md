# TierSlot β Godot実装方針・座標【2026-10-08引き継ぎ】

## 環境
- Godot／GDScript。
- 解像度1920×1080。
- コード化した画素データでピクセルアートを管理。

## 責務分離
### `game_screen.gd`
共通画面、入力、BET、Coin、Roll、Stop、共通リール、共通プレイデータ、Shop遷移。

### `machines/lilith/*.gd`
各台固有ルール、状態、当たり判定、配当計算。

### MachineDisplay用スクリプト
各台固有表示、アニメーション、結果表示、演出切り替え。ゲームロジックと分離。

## 開発ルール
- コード修正時は原則**ファイル全文を提示**。差分だけで済ませない。
- 無関係な処理を変更しない。
- InspectorのPosition／Sizeを勝手に変更しない。
- 実機未確認の変更を「動作確認済み」と表現しない。
- ファイル名は小文字snake_case。
- 既存の画素データを不用意に変更しない。
