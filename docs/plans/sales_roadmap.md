# TierSlot 販売ロードマップ・価格設定案

## 1. 基本方針

TierSlotは36台をすべて完成させてから一括発売するのではなく、**Early Access → 正式版 → DLC → 36台完成**の順番で段階的にコンテンツを追加する。

目的：
- 早い段階でSteamへ公開する
- プレイヤーの反応を以降の開発へ反映する
- 36台完成まで開発を閉じない
- 店舗追加そのものをイベント化する
- 初期購入者には価格面でメリットを与える
- 最終的な全部入り価格を2,000円未満に抑える

## 2. Phase 1：Early Access

**TierSlot Early Access**

収録：
- リリス店舗
- リリス担当6台
- TierSlotの基本システム
- Destiny Roll System
- Machine Tier等の共通システム

価格：**400円を第一候補**（想定範囲：300～500円）

位置付け：TierSlotの最初の一般公開版。

リリス6台を使って、ゲームバランス、UI、操作性、Machine Tier、演出、ゲーム説明、プレイヤーの人気機種などを検証する。

## 3. Phase 2：正式版

**TierSlot Ver.1.0**

追加：
- イヴ店舗
- イヴ担当6台

合計：**2店舗 / 12台**

正式版価格：**600円**

Early Access購入者：**追加購入なしで正式版へアップデート**

Early Accessから購入したプレイヤーは300～500円で正式版を所有できるため、早期購入特典として機能する。

リリスとイヴという性質の異なる2店舗を揃えることで、Destiny Roll Systemによって異なるジャンルのゲームを表現できるTierSlot本来の特徴を提示する。

## 4. Phase 3：大型DLC 第1弾

**桜花炎舞**

追加店舗：
- ヨウコ / 日本
- リンリン / 中国

追加台数：12台

価格：**600円**

本編と合わせた累計：**4店舗 / 24台**

日本・中国を中心とした東アジアの伝統ゲーム、賭博、カード、ダイス、盤上ゲームなどをTierSlot / Destiny Rollへ落とし込む。

## 5. Phase 4：大型DLC 第2弾

**GOLD RUSH**

追加店舗：
- イシス / エジプト周辺
- ソフィア / ヨーロッパ

追加台数：12台

価格：**600円**

本編と合わせた累計：**6店舗 / 36台**

このDLCの実装によって、TierSlotの36台構想が完成する。

## 6. 最終構成

完成版TierSlot：
- リリス：6台
- イヴ：6台
- ヨウコ：6台
- リンリン：6台
- イシス：6台
- ソフィア：6台

合計：**6店舗 / 36台**

さらに、**リブラ**を実装してTierSlot完成形とする。

## 7. 価格体系

| 製品 | 価格 |
|---|---:|
| Early Access | 300～500円（第一候補400円） |
| 正式版TierSlot | 600円 |
| DLC「桜花炎舞」 | 600円 |
| DLC「GOLD RUSH」 | 600円 |

## 8. 総額

**正式版から購入**

本編600円 ＋ 桜花炎舞600円 ＋ GOLD RUSH600円 ＝ **合計1,800円**

**Early Access 400円から購入**

Early Access400円 ＋ 桜花炎舞600円 ＋ GOLD RUSH600円 ＝ **合計1,600円**

Early Access価格を300～500円とした場合：
- 最安：300 + 600 + 600 ＝ **1,500円**
- 最高：500 + 600 + 600 ＝ **1,700円**

したがってEarly AccessからTierSlotを追いかけたプレイヤーは、**1,500～1,700円で全コンテンツを所有可能**。

正式版から購入した場合でも、**1,800円で36台＋リブラまで遊べる構成**を目標とする。

## 9. 現時点の第一候補

1. **Early Access**：リリス6台、400円
2. **TierSlot Ver.1.0**：リリス＋イヴ、12台、600円
3. **桜花炎舞**：ヨウコ＋リンリン、12台追加、600円
4. **GOLD RUSH**：イシス＋ソフィア、12台追加、600円
5. **TierSlot 完成**：6店舗、36台＋リブラ

最終価格：
- Early Access組：**1,600円**
- 正式版から購入：**1,800円**

## 10. 販売コンセプト

高価格・大規模インディー作品を目指すのではなく、

> 「安いから試してみたら、異常なほどゲームが入っていた」

と思ってもらえる価格と物量を狙う。

Early Accessからプレイヤーと一緒にTierSlotを育て、店舗と店主が順番に登場することで世界そのものを拡張していく。

最終的に、**6人の店主・6店舗・36台・Destiny Roll System・リブラ**を揃え、TierSlotを完成させる。
