## 0. 全台共通仕様

- 3リール独立、各1～6均等、全216通り。
- MT0～6、MT0開始、MT6上限。
- **プレイヤー自身のTriple（111～666）累計6回でMT+1、DAY+1**。MT6以降も6回ごとのDAY+1は継続。
- CPU・ディーラー・敵などプレイヤー以外のTripleはMTに加算しない。プレイヤーRollなら通常・特殊状態・リーチ中・天和・ホームラン・役成立Rollを問わず加算。
- 123／456は順不同（123、132、213、231、312、321など）。BT上昇役として採用する台ではBT+1。

## 1. チンチロ

### コンセプト・BET・親子
プレイヤー対CPU、引き分けは親勝ち。BET：**100／500／1,000 Coin**。台入場直後はCPU親、以後ゲームごとにCPU親／プレイヤー親を交互に変更。親子で配当倍率は変えず、親の優位性は同点勝利のみ。

### 投擲
1投3D6、最大3投。役または通常の目が成立した時点で終了。目なしなら再投擲、3投目も目なしなら3投目を最終結果とする。

### 役・勝敗
- **ピンゾロ：** 111、最上位、5倍役。
- **アラシ：** 222／333／444／555／666、3倍役。
- **シゴロ：** 456順不同、2倍役。
- **通常の目：** Pair＋アンマッチ数字（226→6の目、335→5の目）。強さ6＞5＞4＞3＞2＞1。
- **目なし：** 3数字がすべて異なりシゴロ／ヒフミ以外。通常役・目より弱い。双方目なしなら3数字合計値の高い側が勝ち、同値は親勝ち。
- **ヒフミ：** 123順不同、2倍負け役。

強さ：ピンゾロ＞アラシ＞シゴロ＞6の目＞5の目＞4の目＞3の目＞2の目＞1の目＞目なし。ヒフミは特殊負け役。同一結果など通常引き分けは親勝ち。

通常勝敗1倍、シゴロ2倍、アラシ3倍、ピンゾロ5倍、ヒフミ2倍負け。親子倍率補正なし。

**BTなし。** MT育成はプレイヤーTripleのみ。

### シミュレーション目安・設計方針
- 親勝率約54.86%、子勝率約45.14%。
- プレイヤー親期待値約+10.55%、子約-10.55%。
- 完全交互の長期RTP約100%。
- 平均投擲1人約1.75投、1勝負双方合計約3.5投。
- Triple6回平均約216プレイヤーRoll。

**RTP100%特殊台**。MTによるRTP上昇なし。親有利＋親子交代で長期100%。

## 2. ブラックジャック

### 基本・BET・DR
TierSlot式ブラックジャック。Player vs Dealer、21を超えずDealerより高い合計を目指す。BET：**100／500／1,000 Coin**。

```text
destiny = (r1 + r2 + r3 - 3) % 6 + 1
```

DR1～6は各1/6、現在合計へ加算。

### プレイヤー操作
最初の2DRはプレイヤーがレバーを2回引いて**強制HIT**。3Roll目以降HIT／STAND選択可。レバー＝HIT、Enter＝STAND。

HITでは3リール抽選→DR加算、同時に123／456順不同でBT+1、TripleでMT育成+1。

**21：** 自動STAND。何Rollかかっても最終値21で勝利なら特別配当3:2（例：6+6+6+3＝21）。**22以上：** 即BUST、敗北、ディーラー抽選なし。

### ディーラー・勝敗
Player STAND後、Dealerが最初に2DR取得。18以下HIT、19以上STAND、21超過BUST。CPU側出目はBT・MT対象外。

双方21以下なら大きい方勝利、同値PUSH。Dealer BUSTならPlayer勝利。

PUSH＝BET全額返却、利益損失0、BT維持。

### BT・MT・配当【コミット値】
- 初期BT0。Playerの123／456順不同でBT+1（DR加算も実施）。
- 敗北／PUSHでBT維持、勝利時は払い出し後BT0、離席時BT0。
- MTは勝敗／DR確率に影響せず、**勝利時利益倍率**のみ強化。

```text
補正係数 = 0.78 + MT × 0.056 + BT × 0.005
例：MT6, BT2 → 0.78 + 0.336 + 0.010 = 1.126

通常勝利総払い出し = BET + BET × 補正係数
21勝利総払い出し = BET + BET × 1.5 × 補正係数
PUSH = BET返却のみ
敗北 = 0
```

推奨戦略：18以下HIT、19／20 STAND、21自動STAND。

## 3. 野球

### 基本・BET
Player vs CPU、**6イニング制**、延長なし。BET：100／500／1,000 Coin、1試合1回。交互に攻撃、3アウトで攻守交代。6回終了で得点上位が勝ち、同点引き分け。6回表終了時点で後攻側がリードなら6回裏なしで終了。

### STRIKE / BALL
打者ごとにStrikeCount／BallCount。3 STRIKEで三振・1アウト、4 BALLで四球・打者1塁。走者は必要な者だけ押し出す（1塁走者あり→1・2塁、2塁走者のみ→打者1塁・2塁維持、満塁→押し出し1点）。ヒット・ホームラン・直接OUT・三振・四球で打者終了時に両カウント0。

### 出目判定
**Single（3数字すべて異なる）：**
```text
result = (r1 + r2 + r3) % 6 + 1
1～2 → STRIKE
3～5 → OUT
6 → BALL
```
123／456も通常Single判定に加え、Player側ならBT+1。

**Pair（Exactly Pair）：** アンマッチ1～2＝OUT、3～4＝1ベースヒット、5～6＝2ベースヒット。3ベースヒットなし。

1ベースヒット：打者1塁、全走者1塁分進み、本塁越えで得点。2ベースヒット：打者2塁、全走者2塁分進み、本塁越えで得点。

**Triple：** 111～666＝HOME RUN。打者と塁上走者全員生還、塁上クリア。Player TripleのみMT育成。

### BT・CPU・配当【コミット値】
初期BT0。Player攻撃時123／456でBT+1、試合終了時勝敗不問でBT0。CPU側は影響なし。

CPUも同じ出目判定、特別補正・勝率操作・MTによる性能変化なし。

```text
勝利時総払い出し = BET × (1.90 + MT × 0.054 + BT × 0.02)
敗北 = 0
引き分け = 0（BET返却なし）
```

**ブラックジャックと異なりBET返却は別途加算しない。**

## 4. 競馬

### 基本・出走馬
完全同性能の6頭で一直線84マスを競走。初期位置0。賭ける馬は選べず開始時DRでランダム決定。

| DR | 色 | 馬名 |
|---|---|---|
| 1 | 白 | ホワイトエンジェル |
| 2 | 青 | ブルーオーシャン |
| 3 | 黄 | イエローサンダー |
| 4 | 赤 | レッドブレイズ |
| 5 | 茶 | カッパーアロー |
| 6 | 紫 | バイオレットゲイル |

馬決定DR：
```text
destiny = (r1 + r2 + r3 - 3) % 6 + 1
```
DR1～6各1/6。馬決定RollはBET消費なし、BT・MT対象外。馬決定後BET選択：100／500／1,000 Coin。

### レースRoll
レバーONでPlayer馬＋CPU馬5頭の**全6頭がそれぞれ独立3リール抽選**。全頭移動後に一斉ゴール判定し、処理順の有利不利を禁止。

- **Single：** DR1～3＝0マス、DR4～6＝1マス（0／1各50%）。123／456順不同も通常移動、Player馬ならBT+1。
- **Exactly Pair：** 2マス。
- **Triple：** 3マス。Player馬のみMT育成。

初期BT0。Player馬123／456でBT+1、CPU馬はなし。レース終了／離席でBT0、次レースへ持ち越さない。

全頭移動後にposition >= 84を判定。1頭以上到達でそのRollで終了。

### 同着・配当【コミット値】
同一Rollで84以上の馬は全頭同着1位。Player馬が同着1位なら通常配当を同着頭数で分割。例：6,000 Coin→2頭同着3,000／3頭同着2,000。**分割後の小数Coinは切り上げ。**

```text
倍率 = 5.05 + MT × 0.15 + BT × 0.10
単独1着総払い出し = BET × 倍率
同着総払い出し = ceil((BET × 倍率) / 同着頭数)
2着以下 = 0
```
BET返却の別途加算なし。

## 5. 魔界雀

### コンセプト・BET【コミット値】
Tripleを「リーチ→和了」に変換するTierSlot式麻雀。実牌ではなくリーチ／ロン／ツモ／一発／天和／満貫／跳満／倍満／三倍満／役満の演出・点数体系を1～6リールに落とし込む。

**1Roll＝70 Coin**。固定ゲームBETでなくRoll従量課金。

### 通常状態・リーチ
通常Single／Pairはハズレ、123／456順不同でBT+1。

通常状態の**1回目Triple**：リーチ！！！、Triple数字を記憶（例444→4）、RiichiState=true。MT育成カウント。

リーチ中Single／Pairは基本和了なし、123／456でBT+1。

**2回目Triple：**
- 初回と異なる数字（例444→222）＝「ロン！！！」、通常払い出し抽選。
- 同じ数字（例444→444）＝「ツモ！！！」、今回の払い出しランク計算に**特殊加算+10**。実BTは増やさない。

2回目TripleもMT育成カウント。

### 一発
リーチ成立Rollの次を1Roll目として数え、**4Roll以内**に次Tripleで一発、特殊加算+10。5Roll目以降は一発なし。

一発＋同一Tripleのツモなら「一発・ツモ！！！」、特殊加算+20（ツモ10＋一発10）。

### 天和
天和チャンスは①台入場直後の初Roll、②通常払い出し終了後の次の1Roll。

そのRollでTripleなら「天和！！！」、リーチ不要・役満確定、**32,000 Coin**、MT育成加算。天和払い出し後の次Rollも天和チャンスとなるため理論上連続可能。

チャンスRollでTriple以外ならチャンス終了、その出目は通常処理（例123→BT+1）。

### BT・最低保証スコア【コミット値】
初期BT0。123／456でBT+1、通常和了払い出し後／離席でBT0。ツモ・一発の+10は実BTではなく払い出しランク判定用。

**旧仕様の `BT + MT + 特殊加算` は使用しない。**

```text
保証スコア = BT + MT段階補正 + 特殊加算
```

MT段階補正：
| MT | 加算 |
|---|---:|
| 0 | +3 |
| 1 | +3 |
| 2 | +4 |
| 3 | +4 |
| 4 | +5 |
| 5 | +5 |
| 6 | +6 |

ロン+0、ツモ+10、一発+10、一発＋ツモ+20。麻雀点数ランクに合わせた段階成長型。

### 最低保証ランク・配当

|---|---|
| 0～9 | 2,000 Coin以上 |
| 10～19 | 3,900 Coin以上 |

**TierSlot式昇格抽選：** 最低保証ランクから1/6成功で1段階昇格し、再び1/6を繰り返す。失敗または役満到達で終了。例：2,000→成功→3,900→成功→8,000→失敗→8,000払い出し。

払い出し7段階：2,000／3,900／8,000／12,000／16,000／24,000／32,000 Coin。

### 役名表示
2,000／3,900は対応する実在麻雀役をランダム表示。8,000＝満貫、12,000＝跳満、16,000＝倍満、24,000＝三倍満。32,000は実在役満をランダム表示（国士無双、四暗刻、大三元、字一色、緑一色、清老頭、小四喜など）。天和条件成立時のみ「天和」と表示。

### 払い出し後・離席リセット
通常和了／ツモ／一発／役満／天和すべて払い出し後：
```text
BT = 0
RiichiState = false
記憶Triple = null
IppatsuCount = 0
次Roll：天和チャンス = true
```

離席時もBT0、リーチ解除、記憶Triple削除、一発カウント解除。再入場初Rollは天和チャンス。

天和Triple、リーチTriple、ロンTriple、ツモTripleはすべてPlayer TripleとしてMT育成。累計6回で通常どおりMT+1。

## 7. 実装時の重要注意事項

1. **MT育成TripleはPlayer Rollのみ。** CPU側は絶対にカウントしない。
2. **123／456は順不同。**
3. **BTリセットは台ごとに異なる。** BJ＝勝利時のみ0、敗北／PUSHは維持、離席0。野球＝試合終了時必ず0。競馬＝レース終了時必ず0。魔界雀＝払い出し終了／離席時0。チンチロ＝BTなし。
4. **BET返却方式に注意。** BJのみBET返却＋利益。野球／競馬は倍率計算結果そのものが総払い出し。魔界雀は固定Coin。チンチロは倍率方式。
5. **魔界雀のMT補正は段階型。** MTそのものを保証スコアへ入れず、MT0:+3、MT1:+3、MT2:+4、MT3:+4、MT4:+5、MT5:+5、MT6:+6を使用。
6. **野球の先攻／後攻**は検証で50%／50%前提。実装時の50%ランダム採用が自然だが、原資料では未確定。
7. **Coin小数処理：** 競馬同着分割のみ切り上げ確定。BJ・野球などの倍率による小数Coinの共通丸めは未確定。既存共通ルールがあれば使用し、なければ別途決定。
