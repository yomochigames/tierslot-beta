# MachineDisplay 演出仕様【2026-10-08】

> **演出フローと詳細未確定箇所を区別**。ゲームロジックと表示・アニメーションは分離する。

## 共通方針
MachineDisplayは各ゲーム固有の情報・演出を表示する領域。各台固有ロジックをGameScreenへ大量に追加しない。

## EXTEND【演出フロー確定】
- 通常：眠っているチビリリスの静止画。
- Triple成立：**+10G**、AT突入。
- AT中Roll開始：Dance01～08をループ。
- リール停止後：獲得Coin → 残りATゲーム数を順に表示。
- AT中Triple：獲得Coin → **+10G** → 残りゲーム数更新。
- AT終了：眠っている静止画へ戻る。
- チビリリスの最終デザインは未完成。

## COUNTDOWN【確定】
- 通常：`60`（残りRoll数）。
- Rollごとに残り数を減算。
- Triple成立：`BONUS`＋実際の獲得Coin（例：120000）。
- 残り0で終了：`GAME OVER`。
- キャラクター演出なし。数字中心。

## TRINITY【基本確定】
- Triple成立：`TRINITY!!`＋実際の獲得Coin（例：`+6000`）。
- 通常時の表示内容は未確定。

## ZERO-ONE 301【確定】
- 通常：スコア`301`、`ROLL 60`。
- Rollごとにスコア・残りRoll数を更新。
- スコア0：`CLEAR!!`。
- 残りRoll0：`GAME OVER`。
- BUST：スコア据え置き、残りRollのみ減算。

## TEN【演出候補・詳細未確定】
- 通常：`TOTAL 7`など。
- 成功：`TEN!!`。
- 失敗：`BUST`。
- 表示時間・レイアウトは未確定。

## CHAIN【演出候補・詳細未確定】
- 進行中：`CHAIN ×3`／`BONUS 15000`。
- 失敗時：`CHAIN END`／`BONUS 15000`。
- 蓄積BONUSの表示方法・タイミングは未確定。
