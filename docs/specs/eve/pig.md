# TierSlot Pig 暫定仕様

## 1. ゲーム概要

ダイスゲーム「Pig」をベースにしたSCORE蓄積型ゲーム。

2〜6を引いてSCOREを100まで積み上げる。

「1」を引くたびに報酬ランクが低下し、3回目の「1」で全損となる。

## 2. BET

BETは以下の6段階。

- 100 Coin
- 500 Coin
- 1,000 Coin
- 3,000 Coin
- 5,000 Coin
- 10,000 Coin

Machine Tierに応じて順次解放する。

具体的な解放MTは既存台と同様の方式を使用する。

## 3. ゲーム開始

ゲーム開始時：

- SCORE = 0
- MISS = 0

からスタートする。

## 4. Roll判定

### 2〜6

出た数字をそのままSCOREへ加算する。

例：

SCORE 45 → 「6」 → SCORE 51

### 1

SCOREは減少しない。

MISSを+1する。

例：

SCORE 78 / MISS 1 → 「1」 → SCORE 78 / MISS 2

## 5. 成功条件

SCOREが100以上になった時点でゲームクリア。

100ピッタリである必要はない。

クリア時のMISS数によって報酬が変化する。

## 6. 報酬

BET 100 Coin時の基礎報酬。

| MISS | 報酬 |
|---|---:|
| 0 | 20,000 Coin |
| 1 | 15,000 Coin |
| 2 | 7,500 Coin |

BET額が増加した場合、基礎報酬もBET100を基準として比例して増加する。

## 7. 全損条件

3回目の「1」を引いた時点でゲーム終了。

MISS 3：

払い出し 0 Coin

それまで蓄積していたSCOREも失われる。

## 8. BT

BT（Bonus Tier）は使用しない。

PigではSCOREとMISSによってゲーム状態が変化するため、追加のBTシステムは設けない。

## 9. 123 / 456

現時点では特殊効果なし。

123 / 456を利用する仕組みは、将来の拡張要素として残しておく。

## 10. Triple / Machine Tier育成

プレイヤーがRollしたTriple（111〜666）は、通常どおりMachine Tier育成用Tripleとしてカウントする。

ゲーム内のSCORE判定自体は通常のPigルールに従う。

## 11. Machine Tier補正

Machine Tierは最終払い出し額に補正をかける方式とする。

MISS率や「1」の出現率など、Pig本来のゲーム進行には影響させない。

具体的なMT0〜MT6の補正値は、実装時のRTP調整段階で改めて決定する。

目標RTP：

- MT0：約90％
- MT6：約105％

## 12. 現時点の確率目安

補正なしの場合：

| 結果 | 確率目安 |
|---|---:|
| MISS 0で100到達 | 約1.02％ |
| MISS 1で100到達 | 約4.23％ |
| MISS 2で100到達 | 約9.16％ |
| MISS 3で全損 | 約85.60％ |
| 100到達合計 | 約14.40％ |

約6.94ゲームに1回の割合で100へ到達する。

平均ゲーム長：約16.76 Roll。

## 13. 設計方針

本家Pigの

「1を引く前にどこまで得点を伸ばせるか」

というPush-your-luck要素を、

「1を引くたびに最終報酬が削られていく」

というTierSlot向けの構造へ変換する。

HOLD選択は使用せず、

Roll
↓
SCORE加算 / MISS
↓
100到達またはMISS3まで継続

というテンポの良いゲーム進行とする。

## 14. 実装時の再検討項目

- MT0〜MT6の正確な払い出し補正率
- 最終的なRTP
- Coin端数処理
- UI / 演出
- BET解放MTの最終確認
- 123 / 456を将来的に使用するか

ゲームの中核ルールについては以上を暫定仕様として採用する。
