# STAR & BELL 仕様メモ

## 基本情報
名称：STAR & BELL（スター＆ベル）

アメリカ／イヴ枠のクラシックスロット台。
古典的な3リールスロットをベースに、TierSlot / Destiny Roll System向けに再構築する。

## コンセプト
「育てるほど、リールそのものが強くなるクラシックスロット」

配当補正によってMT差を作るのではなく、Machine Tierによってリール構成そのものを変更する。
MTが上がるほど当選しやすいリールへ成長する。

## シンボル
全6種類。

- ★ STAR
- ♣ CLUB
- ♠ SPADE
- ♦ DIAMOND
- ♥ HEART
- 🔔 BELL

★は頻出する基本小役シンボル。
🔔は最高位シンボル。

## 基本ゲーム
3リール・1ライン。
1Rollごとに3リールを停止し、停止したシンボルの組み合わせで即座に配当を判定する。
特殊ゲームやボーナスゲームは設けない。

Roll → 停止 → 判定 → 配当 → 次Roll

MTが上がることで、期待値だけでなく実際に当たりやすくなったことを体感できる設計とする。

## MT育成
プレイヤーが成立させたTriple（★★★～🔔🔔🔔）をMT育成カウント対象とする。
123 / 456による特殊効果はなし。
BTは使用しない。

## BET
BETはMTに応じて順次解放。

100 / 500 / 1,000 / 3,000 / 5,000 / 10,000 Coin

最高BET10,000時、🔔🔔🔔 → 1,200,000 Coin

## 筐体育成表示
筐体に★を配置し、MTに応じて★の数を増やす。

| MT | ★ |
|---|---|
| MT0 | ★ |
| MT1 | ★★ |
| MT2 | ★★★ |
| MT3 | ★★★★ |
| MT4 | ★★★★★ |
| MT5 | ★★★★★★ |
| MT6 | ★★★★★★★ |

★はアメリカを象徴するモチーフであると同時に、STAR & BELLの育成状況を表す。
大掛かりなMTアップ演出は不要。
筐体そのものが少しずつ★で装飾されていくことで成長を表現する。

## 演出方針
特殊演出は基本的に使用しない。
クラシックスロットらしく、「回す → 止まる → 当たる」というシンプルさを重視する。

## STAR & BELLの特徴
★＝頻出小役・アメリカ・成長
🔔＝最高役・クラシックスロット

という二つのシンボルを台の中心に置く。
配当をMTで補正するのではなく、リールそのものが成長することが最大の特徴。

STAR & BELL、以上の仕様で採用。
