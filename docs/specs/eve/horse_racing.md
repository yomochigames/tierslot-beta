# TierSlot2 競馬台 仕様【本採用】

> 店舗：イヴ（当時の仕様分類）  
> 状態：本採用  
> 注：提出された仕様を記録。RTPは想定値として記載する。

## 基本コンセプト

6頭の競走馬によるレース。開始時にDestiny Roll（DR）でプレイヤーが賭ける馬をランダム決定し、その後BETを選択。プレイヤーは自身の馬の走行抽選をレバーで行い、残り5頭はゲーム側が同時に独立抽選する。1着で配当獲得。

## 出走馬

| 色 | 名前 |
|---|---|
| 白 | ホワイトエンジェル |
| 青 | ブルーオーシャン |
| 黄 | イエローサンダー |
| 赤 | レッドブレイズ |
| 茶 | カッパーアロー |
| 紫 | バイオレットゲイル |

馬体・ゼッケン・装具などの具体的なカラー表現はビジュアル制作時に決定。6頭の基本走行性能は完全に同一。MTによる走行性能差なし。

## コース

一直線型、ゴールまで**84マス**。6頭同時スタート。平均約60ロール強で決着を想定。

## Destiny Roll（DR）

3リールからDR1〜6を均等算出。

```text
destiny = (r1 + r2 + r3 - 3) % 6 + 1
```

各DRの確率は1/6。開始時のDRで今回賭ける馬を決定し、その後BETを選択。

## BET

馬はプレイヤーが選択できず、DR決定馬へBET。

| キー | BET |
|---|---:|
| 左 | 100 Coin |
| 下 | 500 Coin |
| 右 | 1,000 Coin |

BET決定後レース開始。

## 1ロールの流れ

1. プレイヤーがレバーを引く。
2. プレイヤー馬の3リールを抽選。同時に残りCPU5頭もそれぞれ独立して3リール抽選。
3. 6頭分の移動量を決定。
4. 6頭を同時に移動。
5. 全頭移動完了後にゴール判定。

**処理順による有利不利は禁止。**

## 移動量

| 出目 | 移動 |
|---|---|
| Single／DR1〜3 | 0マス |
| Single／DR4〜6 | 1マス |
| Pair | 2マス |
| Triple | 3マス |

Singleの0マス／1マスは各50%。

## Bonus Tier（BT）

プレイヤー馬のRollで**123または456（順不同）**が成立するとBT+1。通常の移動判定も実施する。BTは当該レースの勝利配当倍率を強化。CPU馬の123／456はプレイヤーBTに影響しない。

### BTリセット

- レース終了時：BT=0
- 競馬台から離席時：BT=0
- 次レースへの持ち越しなし

## Machine Tier（MT）

MT最大6。馬の走行性能は変えず、勝利時配当倍率のみ上昇。

## 配当倍率

```text
倍率 = 5.05 + (MT × 0.15) + (BT × 0.10)
```

例：
- MT0／BT0 → 5.05倍
- MT6／BT0 → 5.95倍
- MT6／BT4 → 6.35倍

MT6で平均的に6倍前後の払い戻しを狙える設計。

**想定RTP：** MT0約90% → MT上昇で段階的に上昇 → MT6約105%前後。

## 勝利条件

84マス以上に到達した馬が1着。1着発生ターンでレース終了。ただし**6頭すべての移動を完了してから順位判定**する。

## 同着

同一ターンに複数馬が84マス以上へ到達した場合、同着1位。

プレイヤー馬が同着1位の場合、**通常配当÷同着頭数**。

例：通常配当6,000 Coin → 2頭同着3,000 Coin／3頭同着2,000 Coin。

配当計算で小数が発生したら**小数点以下切り上げ**。

## 2着以下

配当なし。1着のみ払い出し対象。複勝・2着・3着配当は採用しない。

## レース終了

- プレイヤー馬1着：**BET × 最終配当倍率**を払い出し。同着なら同着頭数で分割。
- プレイヤー馬2着以下：払い出しなし。
- いずれもBT=0で終了。

## 基本ゲームフロー

```text
競馬台へ移動
↓
Destiny Roll → 今回賭ける馬を1頭決定
↓
BET選択（100 / 500 / 1,000 Coin）
↓
6頭スタート
↓
プレイヤーがレバーON
↓
プレイヤー馬＋CPU5頭を同時抽選
  Single → DRによって0 or 1マス
  Pair → 2マス
  Triple → 3マス
  123 / 456 → BT+1（プレイヤー馬）
↓
6頭同時移動
↓
ゴール判定
  全頭84マス未満 → 次のロール
  1頭以上84マス以上 → レース終了
↓
プレイヤー馬1着 → 配当
プレイヤー馬2着以下 → 配当なし
↓
BT=0
↓
次のゲーム
```
