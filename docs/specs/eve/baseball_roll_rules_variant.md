# TierSlot2 野球 — 出目判定・基本ルール案

> **資料区分：個別仕様（受領原文に基づく）**  
> **注意：** 既存の2026-08-12付5台仕様とは、Single判定・Pair判定が異なる。時系列・優先順位が確定していないため、本資料を別版として保存し、既存資料は上書きしない。

## 基本ルール

- 6イニング制
- 延長戦なし
- プレイヤー側と敵側が交互に攻撃
- 3アウトで攻守交代
- 6回終了時、得点が多い側の勝利
- 同点の場合は引き分け

## 出目判定

### シングル

3つの数字がすべて異なる場合。

3リールの出目の合計値を6で割り、その余りに+1した値で結果を決定する。

```text
result = (r1 + r2 + r3) % 6 + 1
```

| result | 判定 |
|---|---|
| 1～3 | STRIKE |
| 4～5 | OUT |
| 6 | BALL |

- 連番による特殊判定なし
- 123、234、456なども通常のシングルとして判定

### ストライク

- STRIKEを3回で三振
- 三振で1アウト
- 打者交代時にストライク、ボールをリセット

### ボール

- BALLを4回でフォアボール
- フォアボールで打者は1塁へ進む
- 打者交代時にストライク、ボールをリセット

### ペア

2つの数字が同じ場合、ペアになっていない**アンマッチ数字**でヒット内容を決定する。

| アンマッチ数字 | 判定 |
|---|---|
| 1～3 | 1ベースヒット（シングルヒット） |
| 4～5 | 2ベースヒット（ツーベース） |
| 6 | 3ベースヒット（スリーベース） |

例：

- 221 → アンマッチ数字1 → 1ベースヒット
- 225 → アンマッチ数字5 → 2ベースヒット
- 226 → アンマッチ数字6 → 3ベースヒット

### トリプル

111～666 → **HOME RUN**

- 打者と塁上の全ランナーが生還
- 得点後、塁上のランナーはすべていなくなる

## 走塁

- 1ベースヒット → 打者およびランナーが1塁分進む
- 2ベースヒット → 打者およびランナーが2塁分進む
- 3ベースヒット → 打者およびランナーが3塁分進む
- ホームラン → 打者を含む全ランナーが生還

## ゲームの基本進行

```text
攻撃開始
↓
リールを回す
↓
出目判定
↓
STRIKE / OUT / BALL / HIT / HOME RUN
↓
3アウトまで継続
↓
攻守交代
↓
6イニング終了まで繰り返す
↓
最終得点で勝敗決定
```
