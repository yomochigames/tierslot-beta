# TierSlot2 ブラックジャック台 仕様【本採用】

> 店舗：イヴ／アメリカ  
> ステータス：**本採用（提出された仕様の記録）**  
> **版管理上の注意：** 2026-08-12付の旧5台まとめ（`docs/archive/eve_machines_five_2026-08-12.md`）では配当補正係数が `0.78 + MT × 0.056 + BT × 0.005` だったが、**本書では `0.88 + MT × 0.03 + BT × 0.005`**。数値を混合せず、本書の記載を保持する。RTPは本書に記載された目標値であり、実測値として扱わない。

## 基本コンセプト

Destiny Roll（DR）の1〜6をカードの数字として使用するTierSlot式ブラックジャック。プレイヤー vs ディーラーの1対1。21を超えない範囲でディーラーより高い数字を目指す。

- レバー：HIT
- Enterキー：STAND

## BET

ゲーム開始時にBET額を選択する。

| 操作 | BET |
|---|---:|
| 左キー | 100 Coin |
| 下キー | 500 Coin |
| 右キー | 1,000 Coin |

BET決定後にゲーム開始。

## Destiny Roll（DR）

3リールの出目から1〜6を均等に算出する。

```text
destiny = (r1 + r2 + r3 - 3) % 6 + 1
```

DR1〜6は各1/6。算出されたDRをブラックジャックの数字として現在合計値へ加算する（例：DR4 → 合計値+4）。

## ゲーム開始

最初の2DRは**強制HIT**。プレイヤー自身がレバーを2回引く。

1. 1ロール目 → DR加算
2. 2ロール目 → DR加算
3. 3ロール目以降 → HIT／STANDを選択可能

## プレイヤー操作

- **レバー＝HIT：** 3リール回転、DRを現在値へ加算。
- **Enter＝STAND：** 現在合計値で勝負し、ディーラーターンへ移行。

## 21

合計値がちょうど21になった場合は自動STAND。それ以上HIT不可。ディーラーターンへ移行し、21で勝利した場合は特別配当。

## BUST

合計値が22以上なら「BUST」、即敗北。ディーラー抽選なし、払い出しなし。

## ディーラー

プレイヤーSTAND後に抽選開始。ディーラーもDR1〜6を加算し自動行動する。

- 18以下 → HIT
- 19以上 → STAND
- 21超過 → BUST（プレイヤー勝利）

## 勝敗判定

双方21以下の場合：

- プレイヤー ＞ ディーラー → 勝利
- プレイヤー ＜ ディーラー → 敗北
- プレイヤー ＝ ディーラー → PUSH

## PUSH

同点はPUSH。勝敗なし。BET全額返却。BTはリセットしない。

## 通常勝利

通常勝利の基本利益配当は**1：1**。

例：BET 500 Coin → 基本利益500 Coin。

最終払い出しにはMT・BTによる配当補正を適用する。

## 21勝利

合計値21で勝利した場合、基本利益配当は**3：2**。

例：BET 1,000 Coin → 基本利益1,500 Coin。

最終払い出しにはMT・BTによる配当補正を適用する。

## Bonus Tier（BT）

プレイヤーのRollで123または456が**順不同**で成立するとBT+1。DRによる数字加算も通常どおり実行。

例：出目123 → DR4 → 合計値+4 → BT+1。

## BT持ち越し

- 敗北 → BT維持
- PUSH → BT維持
- 勝利 → 払い出し終了後にBT0

負けが続くほどBTが蓄積し、次回勝利時の配当が少しずつ強化される。

## 離席

ブラックジャック台から離れたらBT0。次回プレイへ持ち越さない。

## Machine Tier（MT）

MT上限6。MTは勝率やDR抽選確率を変更せず、勝利時の配当補正に使用する。

## 配当補正

**勝利時の配当補正係数（本書記載値）：**

```text
0.88 + (MT × 0.03) + (BT × 0.005)
```

MTは恒久的、BTはプレイ中に蓄積する一時的な配当強化。

例：MT6、BT2 → 0.88 + 0.18 + 0.01 = **1.07**。

## 最終配当

- **通常勝利：** 基本1：1配当 × 補正係数
- **21勝利：** 基本3：2配当 × 補正係数
- **PUSH：** 補正なし、BET全額返却
- **敗北：** 払い出しなし

※本書は基本利益と最終払い出しを区別して記述している。元BET返却を含む総払い出しの明示的な数式は原文にないため、ここでは補わない。

## RTP設計

**目標値：**

- MT0 → 約90%
- MT上昇に伴い段階的に上昇
- MT4付近 → 約100%
- MT6 → 約105%

MT／BTでDRや勝敗確率を操作せず、勝利時配当を強化してRTPを調整する。

## 基本ゲームフロー

```text
BET選択（100 / 500 / 1,000 Coin）
↓
ゲーム開始
↓
レバー → 強制HIT① → DR加算
↓
レバー → 強制HIT② → DR加算
↓
3ロール目以降
  レバー → HIT
  Enter → STAND
↓
HIT時
  DRを現在値に加算
  123 / 456成立 → BT+1
↓
21到達 → 自動STAND
22以上 → BUST・即敗北
↓
STAND
↓
ディーラー抽選開始
  18以下 → HIT
  19以上 → STAND
  22以上 → BUST
↓
勝敗判定
  勝利 → 通常1：1／21なら3：2
       → MT・BT補正 → 払い出し → BT0
  敗北 → 払い出しなし → BT維持
  PUSH → BET全額返却 → BT維持
↓
次のゲーム
```
