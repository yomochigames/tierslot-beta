## 目的と経済循環
無料でCoinを稼ぐ基礎金策。Coinが0でも再起可能。

```text
MINING → ORE → SELL → COIN → SLOT → MINING
```

## 鉱石売却【確定】
- 採掘中は鉱石を蓄積。
- 画面に**TOTAL VALUE**を常時表示し、獲得のたび更新。
- **Escキー**で以下を順に実行：
  1. 所持鉱石をすべて売却。
  2. TOTAL VALUE分をCoinへ加算。
  3. 鉱石所持数を0にする。
  4. SAVE。
  5. Shopへ戻る。
- 確認ダイアログなし、個別売却なし。
