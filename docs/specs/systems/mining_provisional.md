# TierSlot 採掘システム 暫定仕様

> **ステータス：暫定仕様**  
> 初期軍資金0 Coin案は**検討中**。記載された期待値は原案の概算として保存し、検証済み数値とは区別する。

## 1. コンセプト

スロットを遊ぶためのCoinを獲得する採掘コンテンツ。3個のDR6（6面ダイス相当）をRollし、出目によって鉱石を獲得する。

採掘自体はCoinを消費しない。スロットでCoinを使い切っても採掘から再起できる。

```text
採掘 → 鉱石獲得 → 鉱石売却 → Coin獲得
     → スロットをプレイ → Coin不足時は再び採掘
```

## 2. Roll

DR6を3個使用。

- **Single：** 3個すべて異なる。獲得なし。
- **Pair：** 2個が同じ。**Coal（石炭）**を獲得。ペア数字・アンマッチ数字は報酬量に影響しない。
- **Triple：** 3個すべて同じ。数字によって鉱石を決定。

| Triple | 鉱石 |
|---|---|
| 111 | Copper |
| 222 | Iron |
| 333 | Silver |
| 444 | Gold |
| 555 | Mithril |
| 666 | Orichalcum |

## 3. 出目確率

全216通り。

| 役 | 組合せ | 確率 |
|---|---:|---:|
| Single | 120/216 | 55.56% |
| Pair | 90/216 | 41.67% |
| Triple | 6/216 | 2.78%（1/36） |

111、222、333、444、555、666はそれぞれ**1/216**。

## 4. 鉱石・売却価格

| 成立役 | 鉱石 | 売却価格 |
|---|---|---:|
| Pair | Coal（石炭） | 10 Coin |
| 111 | Copper（銅） | 100 Coin |
| 222 | Iron（鉄） | 500 Coin |
| 333 | Silver（銀） | 1,000 Coin |
| 444 | Gold（金） | 3,000 Coin |
| 555 | Mithril（ミスリル） | 5,000 Coin |
| 666 | Orichalcum（オリハルコン） | 10,000 Coin |

鉱石は獲得時に即Coinへ変換せず、**所持品として蓄積し、売却時にCoinへ変換する案**。

## 5. Pickaxe Tier

ツルハシのTierを設定。

- 初期Tier：**1**
- 最大Tier：**6**
- **Tripleを6回成立させるごとにPickaxe Tier+1**
- Tier6でカンスト。

| 段階 | 必要Triple |
|---|---:|
| Tier1 → 2 | 6回 |
| Tier2 → 3 | 6回 |
| Tier3 → 4 | 6回 |
| Tier4 → 5 | 6回 |
| Tier5 → 6 | 6回 |
| **合計** | **30回** |

Triple確率1/36から、Tier6到達の期待値は**30×36＝約1,080 Roll**。

## 6. 鉱石獲得個数

Pair／Triple成立時、**1～現在のPickaxe Tier**から均等抽選して獲得個数を決定。

| Tier | 個数 | 平均 |
|---|---|---:|
| 1 | 1 | 1 |
| 2 | 1～2 | 1.5 |
| 3 | 1～3 | 2 |
| 4 | 1～4 | 2.5 |
| 5 | 1～5 | 3 |
| 6 | 1～6 | 3.5 |

例：
- Tier4、Pair → Coal×1～4
- Tier4、333 → Silver×1～4
- Tier4、666 → Orichalcum×1～4
- Tier6、Pair → Coal×1～6
- Tier6、666 → Orichalcum×1～6

## 7. Pickaxe Tier育成中の期待値（原案概算）

Tier1→Tier6に必要なTripleは30回。各Tierで6回ずつTripleを経験。

| Tier | Triple鉱石の平均総獲得個数 |
|---|---:|
| 1 | 約6個 |
| 2 | 約9個 |
| 3 | 約12個 |
| 4 | 約15個 |
| 5 | 約18個 |
| **合計** | **約60個** |

Triple数字1～6は等確率なので、Tier6到達時の平均はCopper、Iron、Silver、Gold、Mithril、Orichalcumが**各約10個**。

PairによるCoalも含めたTier6到達までの平均売却価値は、原案概算で**約205,000 Coin**。

Orichalcumが高価なため、実際の獲得Coinは大きく変動する。

## 8. Tier6カンスト後（原案概算）

- Pair／Triple時：1～6個（平均3.5個）。
- 収益期待値：**1 Roll約332 Coin**。
- 1,000 Roll：約332,000 Coin。
- 666成立時：Orichalcum×1～6＝**10,000～60,000 Coin相当**。ジャックポット的存在。

## 9. 初期軍資金【検討中】

**従来：** ゲーム開始時60,000 Coin。

**新案：** ゲーム開始時**0 Coin／Pickaxe Tier1**。初期60,000 Coinを廃止し、採掘で最初のCoinを作る。

Pairは約41.67%で成立するため、Pair → Coal×1 → 売却 → 10 Coinからゲーム開始できる。

```text
0 Coin → 採掘 → 鉱石売却 → Coin獲得
       → スロット → Coinが尽きたら採掘へ
```

採掘は無料なのでCoin0でも進行が詰まない。

## 10. 現在の方向性

採掘は「スロットとは別の大きな本編」ではなく、**基礎金策＋Pickaxe Tier育成**として位置づける。

- 高価な鉱石でスロット軍資金を一気に確保できる。
- **666 → Orichalcum**が採掘側のジャックポット。

```text
MINING → ORE → SELL → COIN → SLOT → MINING
```

「最初は石炭を掘って10 Coinを作るところから始まり、最終的に**6,660,000 Coinの寄付**を目指す」という成長構造案。
