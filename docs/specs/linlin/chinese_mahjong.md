# TierSlot 中国式麻雀 初期プロット

> **店舗：リンリン／中国**  
> **ステータス：初期プロット。未確定項目は未確定のまま記録する。**

## 基本コンセプト

- リンリン店舗の中国式麻雀台。
- ヨウコ店舗の日本式麻雀とは別ゲームとして設計する。
- 日本式麻雀の「リーチ→和了待ち」ではなく、複数Rollで手牌を構築し、最終的な中国麻雀の番種で報酬を決めるHand Building型とする。
- プレイヤーによる牌選択、捨て牌選択、鳴きなどの裁量は基本的に入れない。
- 「Roll → 牌獲得 → 自動整理 → 次Roll」のテンポを重視する。

## リールと麻雀牌

- リールの出目と麻雀牌の抽選は別RNGとする。
- リールで麻雀牌そのものを生成しない。
- 麻雀牌はゲーム内部の牌山から抽選する。
- 取得した牌は自動的に手牌へ追加・整理される。
- リール側ではTriple、123/456などDestiny Roll固有の判定を行う。

## 基本ゲーム進行

- 固定Roll制を基本とする。
- 複数Rollを使って手牌を構築する。
- 最終Roll終了後、自動的に最適な和了形・番種を判定する。

1. GAME START
2. 牌山を生成・シャッフル
3. Roll
4. 麻雀牌を獲得
5. 手牌へ自動追加
6. 役・面子候補を自動更新
7. 規定Roll数まで繰り返す
8. 最終手牌を自動解析
9. 和了形および番種判定
10. 払い出し

※規定Roll数、初期手牌枚数、1Rollあたりの取得牌数などは今後シミュレーションして決定する。

## 手牌の基本形

中国麻雀の基本構造である**4面子＋1雀頭**を基本和了形とする。

**面子：**
- 順子（Chow / 吃）
- 刻子（Pung / 碰）
- 必要に応じて槓子（Kong / 槓）

**雀頭：** 同一牌2枚。

プレイヤーは手牌操作を行わず、成立する組み合わせはゲーム側が自動的に最適化する。

## 番種・役

日本式麻雀との差別化のため、リーチ・一発・日本式ドラなどを中心には使用しない。

中国麻雀らしい番種を払い出し要素として採用する。

**初期候補：**
- 碰碰和
- 清一色
- 混一色
- 七対
- 清龍
- 三色系
- 大三元
- 字牌系
- その他、中国麻雀を象徴する分かりやすい番種

最終的な採用番種・点数は後で調整する。

複数番種の複合を許可し、成立した番種によって最終払い出しを上昇させる方向を検討する。

## 123 / 456 ― 花牌システム

123または456を順不同で引いた場合、通常のBT加算ではなく**花牌獲得イベント**とする。

**発生確率：**
- 123 = 6 / 216
- 456 = 6 / 216
- 合計 = 12 / 216
- 約1/18（約5.56%）

### 123成立

四季牌から花牌を獲得。

- 春
- 夏
- 秋
- 冬

### 456成立

四君子牌から花牌を獲得。

- 梅
- 蘭
- 菊
- 竹

花牌は通常手牌には含めず、専用Collectionとして画面上に表示する。

## 花牌ボーナス

花牌は麻雀本体とは別のCollection Bonusとして機能する。

**初期案：**
- 花牌1枚獲得 → 小BonusまたはScore加算
- 春夏秋冬4枚完成 → SEASON BONUS
- 梅蘭菊竹4枚完成 → FLOWER BONUS
- 8花すべて完成 → 超上位Bonus

花牌の重複を許可するか、未獲得牌を優先するかは未決定。

1ゲーム内Collectionにするか、複数ゲームをまたいで蓄積するかも今後検討する。

## Triple

- 111～666のTripleはTierSlot共通のMachine Tier育成判定に使用する。
- Tripleを中国麻雀固有の追加イベントにも利用するかは未決定。
- 花牌イベントとは独立して扱う。

## ゲーム性の二層構造

中国式麻雀台では、2種類の進行を同時に走らせる。

**メイン：** 麻雀牌Collection → Hand Building → 和了・番種判定

**サブ：** Destiny Roll → 123/456 → 花牌Collection

これにより、「あと1牌で面子完成」と「あと1枚で春夏秋冬完成」という2種類の期待感を同時に作る。

## 日本式麻雀台との差別化

**ヨウコ / 日本式麻雀**
- リーチ
- 一発
- ツモ
- 役満
- 当たりを待つゲーム性

**リンリン / 中国式麻雀**
- 複数RollによるHand Building
- 中国式番種
- 自動手牌構築
- 花牌Collection
- 完成形を育てるゲーム性

同じ麻雀でもプレイ感を明確に分離する。

## 初期設計方針

「中国麻雀を忠実に一局再現する」のではなく、中国麻雀のHand Building・番種・花牌という特徴を抽出し、プレイヤー裁量なしの固定Rollゲームとして再構築する。

リールは麻雀牌そのものではなくDestiny Roll判定装置として使用し、麻雀牌は独立RNGから取得する。

中国式麻雀台の中心的な特徴は、

**Hand Building × Chinese Scoring Pattern × Flower Collection**

とする。
