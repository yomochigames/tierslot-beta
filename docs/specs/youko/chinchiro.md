# TierSlot チンチロ台 仕様

## コンセプト
- TierSlotの1〜6×3リールを使用してチンチロを再現する
- プレイヤー vs コンピューター（CPU）の一騎打ち
- 親子制を採用
- RTPは理論上100%を基本方針とする
- MTによって勝率や配当率は変化させず、BET額の選択肢のみ増加する

## 基本ルール
- 1〜6の数字を使用した3リール
- プレイヤーとCPUがそれぞれ1回ずつ抽選する
- 振り直しなしの一発勝負
- 親と子は1ゲームごとに交代する
- 酒場など別画面からチンチロ台へ移動した場合、必ずCPUが親からスタートする
- 台を出入りすることでプレイヤーが有利な親状態を選択することを防止する

## BET

| MT | 選択可能BET |
|---|---|
| MT0〜2 | 100 Coin |
| MT3〜4 | 100 / 500 Coin |
| MT5〜6 | 100 / 500 / 1,000 Coin |

※以降のMTのBET額は未定。

## BET時の資金処理
- BET額とは別に、そのゲームで発生し得る最大損失額を確認する
- 最大損失を支払えない場合、そのBETではゲームを開始できない
- ゲーム開始時に最大損失分を支払い可能額としてロックする
- 勝負終了後、実際の勝敗・倍率に応じた金額のみ精算する
- 未使用のロック分はプレイヤーへ戻す

例：BET 100、最大損失倍率 ×5の場合、最大500 Coinの支払い能力が必要。

## 出目・役

### 通常の目
同じ数字が2個＋異なる数字が1個の場合、ペアになっていない数字を「目」とする。

例：
- 225 → 5の目
- 663 → 3の目
- 414 → 1の目

通常目の強さ：

6の目 ＞ 5の目 ＞ 4の目 ＞ 3の目 ＞ 2の目 ＞ 1の目

### シゴロ
456（順不同）
- 強役
- 倍率：×2

### ゾロ目
222 / 333 / 444 / 555 / 666
- 強役
- 倍率：×3

### ピンゾロ
111
- 最強役
- 倍率：×5

### ヒフミ
123（順不同）
- 成立した側が即敗北
- 倍率：×2負け
- 相手の出目を待たずに勝敗確定

### 目なし
上記のどの役にも該当しない出目。

例：245、135など。

## 目なし同士の勝敗
- 双方が目なしの場合、3リールの出目合計を比較する
- 合計値が大きい側の勝利

例：

プレイヤー：245 → 合計11

CPU：135 → 合計9

→ プレイヤー勝利

- 合計値まで同じ場合は親の勝利

## 同じ役になった場合
- 通常目などで双方の強さが同じ場合は親の勝利
- 引き分けは存在しない

## 親子
- チンチロ台へ入った直後は必ずCPUが親
- 1ゲーム終了するたびに親子を交代

| ゲーム | 親 | 子 |
|---|---|---|
| 1 | CPU | プレイヤー |
| 2 | プレイヤー | CPU |
| 3 | CPU | プレイヤー |

以降繰り返し。

## 配当・損失
- 通常勝敗：±BET ×1
- シゴロ：×2
- ゾロ目：×3
- ピンゾロ：×5
- ヒフミ：×2負け
- 特殊役による倍率はCPU側にも同条件で適用する
- プレイヤーだけ損失額に上限を設けるような補正は行わない
- プレイヤーとCPUで同一ルールを使用する

## 例：BET 100

| 結果 | 収支 |
|---|---:|
| 通常勝利 | +100 Coin |
| 通常敗北 | -100 Coin |
| シゴロによる勝利 | +200 Coin |
| シゴロによる敗北 | -200 Coin |
| ゾロ目による勝利 | +300 Coin |
| ゾロ目による敗北 | -300 Coin |
| ピンゾロによる勝利 | +500 Coin |
| ピンゾロによる敗北 | -500 Coin |
| ヒフミ | 即敗北 -200 Coin |

## RTP方針
- 親と子は完全に同じ抽選確率
- 特殊役の利益・損失倍率も対称
- 親有利のルールを採用する代わりに、プレイヤーとCPUが1ゲームごとに親子を交代する
- 長期的にはプレイヤーとCPUが同条件になるよう設計
- 理論RTP 100%を目標とする
- MTが上昇してもRTPは変更しない

## MTの役割
- MTによる出目確率の変更なし
- MTによる配当倍率の変更なし
- MTによるCPUの強さ変更なし
- MT上昇によって高額BETを解禁する

「MTが高いほど有利」ではなく、
「MTが高いほど大きな勝負ができる」台とする。
