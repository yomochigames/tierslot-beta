## 基本仕様
- 1ロール：50 Coin
- リール：1〜6
- 3リールで抽選
- Machine Tier（MT）最大：6
- Bonus Tier（BT）を使用

**重要事項：** 本家の点数体系をリスペクトしたいので、BET額は変更不可とする。

## 通常出目
- シングル：ハズレ
- ペア：ハズレ
- 123・456：順不同で成立、BT +1

## トリプル

### 1回目のTriple
「リーチ！！！」発生。
- Tripleの数字を記憶
- リーチ状態へ移行
- 次のTriple成立を待つ

例：444 → リーチ！！！ → 「4」を記憶

### 2回目のTriple
1回目に記憶したTripleと比較する。

**異なるTriple**（例：444 → 222）
- 「ロン！！！」
- 通常の払い出し抽選へ

**同じTriple**（例：444 → 444）
- 「ツモ！！！」
- BT +10扱い
- 払い出し抽選へ

## 一発
リーチ成立後、4ロール以内に次のTripleを引くと成立。

「一発！！！」
- BT +10扱い
- ツモとの複合可能

例：444 → リーチ → 3ロール後 → 444 → 「一発・ツモ！！！」（BT +20扱い）

## 天和
以下のどちらかで成立。

1. 酒場から魔界雀へ移動した後の初ロールでTriple
2. 通常の払い出し終了後、次の1ロール目でTriple

成立時：
- 「天和！！！」
- リーチを経由せず即当たり
- 役満確定
- 32,000 Coin払い出し

## 払い出しランク判定
通常当たり時は、**BT ＋ MT ＋ 特殊加算**によって最低保証ランクを決定する。

特殊加算：
- ツモ：BT +10扱い
- 一発：BT +10扱い
- 一発＋ツモ：BT +20扱い

| 合計値 | 最低保証 |
|---|---|
| 0〜9 | 2,000 Coin以上 |
| 10〜19 | 3,900 Coin以上 |
| 20〜29 | 満貫 8,000 Coin以上 |
| 30〜39 | 跳満 12,000 Coin以上 |
| 40〜49 | 倍満 16,000 Coin以上 |
| 50〜59 | 三倍満 24,000 Coin以上 |
| 60以上 | 役満 32,000 Coin確定 |

最低保証値に上限は設けない。
最終的な払い出し上限は役満32,000 Coin。

## TierSlot式昇格抽選
最低保証ランク決定後、昇格抽選を行う。
- 昇格成功率：常に1/6
- 成功するたびに1段階昇格
- 昇格後、再び1/6で抽選
- 失敗するまで継続
- 役満到達で終了

例：

最低保証 2,000
↓
1/6成功
↓
3,900
↓
1/6成功
↓
満貫
↓
1/6失敗
↓
満貫8,000 Coin払い出し

## 払い出し

| 段階 | 払い出し |
|---|---:|
| 第1段階 | 2,000 Coin |
| 第2段階 | 3,900 Coin |
| 満貫 | 8,000 Coin |
| 跳満 | 12,000 Coin |
| 倍満 | 16,000 Coin |
| 三倍満 | 24,000 Coin |
| 役満 | 32,000 Coin |

## 役名表示

**2,000 / 3,900 Coin**

その点数帯に対応する実在の麻雀役をランダム表示。

**8,000 Coin**：「満貫」

**12,000 Coin**：「跳満」

**16,000 Coin**：「倍満」

**24,000 Coin**：「三倍満」

**32,000 Coin**

実在する役満の役名をランダム表示。

例：
- 国士無双
- 四暗刻
- 大三元
- 字一色
- 緑一色
- 清老頭
- 小四喜
- など

天和条件を満たした場合のみ「天和」を表示。

## 払い出し後
- BTを0にリセット
- リーチ状態解除
- 記憶していたTripleをリセット
- 次の1ロールは天和チャンス

## 離席
魔界雀から酒場などへ移動した場合：
- BTを0にリセット
- リーチ状態解除
- 記憶Tripleをリセット

再び魔界雀へ入った場合、初ロールは天和チャンスとなる。
