# TierSlot 花札 — 日本・ヨウコ枠

## 1. 基本コンセプト

日本／ヨウコ枠の花札台。

ゲーム構造はシンプルなAタイプ。

毎Roll BETを消費し、Triple成立で即決着する。

黄台と同じくTriple待ちのゲーム性を持つが、花札台ではTripleの数字を花札役へ変換する。

## 2. BET

MTに応じた開放式。

- MT0〜1：100 Coin
- MT2：500 Coinまで
- MT3：1,000 Coinまで
- MT4：3,000 Coinまで
- MT5：5,000 Coinまで
- MT6：10,000 Coinまで

BET変更によってRTPは変化しない。

## 3. 基本進行

1RollごとにBETを消費。
↓
3D6をRoll。
↓
Single / Pairの場合はゲーム継続。
↓
Triple成立で即決着。
↓
Tripleの数字に応じて花札役を表示。
↓
配当計算。
↓
払い出し。
↓
BTを1へリセット。
↓
次ゲーム開始。

## 4. BT

初期BT：BT1

123または456成立で、BT+1。

123 / 456は順不同で判定する。

例：123、132、213、231、312、321はすべて123成立扱い。456も同様。

BTはTriple成立まで累積する。

Triple成立後、ゲーム終了時にBT1へリセット。

## 5. Tripleと花札役

### 111：カス

基礎配当：BET ×10

100BET時：1,000 Coin

### 222：中役ランダム表示

以下の中役からランダムで1つ表示。

- 猪鹿蝶
- 赤短
- 青短
- 三光
- 花見で一杯
- 月見で一杯

表示役による配当差はなし。

基礎配当：BET ×20

100BET時：2,000 Coin

### 333：雨四光

基礎配当：BET ×30

100BET時：3,000 Coin

### 444：四光

基礎配当：BET ×40

100BET時：4,000 Coin

### 555：五光

本機最高役。

基礎配当：BET ×100

100BET時：10,000 Coin

### 666：CPUあがり

プレイヤー敗北。

配当：0 Coin

画面上ではCPU側に役が成立し、先にあがられたことを表現する。

## 6. Triple配当一覧

| Triple | 表示役 | 基礎倍率 |
|---|---|---:|
| 111 | カス | ×10 |
| 222 | 猪鹿蝶〜三光等 | ×20 |
| 333 | 雨四光 | ×30 |
| 444 | 四光 | ×40 |
| 555 | 五光 | ×100 |
| 666 | CPUあがり / LOSE | ×0 |

## 7. 配当補正

花札台専用補正式を使用。

`補正率 = 0.957 + MT×0.027 + BT×0.005`

最終配当：

`最終配当 = BET × 役倍率 × 補正率`

小数点以下は切り捨て。

## 8. RTP目安

現行仕様でのRTP目標値。

| MT | RTP目安 |
|---|---:|
| MT0 | 約90.0% |
| MT1 | 約92.5% |
| MT2 | 約95.0% |
| MT3 | 約97.5% |
| MT4 | 約100.0% |
| MT5 | 約102.5% |
| MT6 | 約105.0% |

MT4付近で期待値100%を跨ぎ、MT6で約105%となる設計。

## 9. Machine Tier育成

プレイヤーが成立させたTripleは、111〜666すべてMT育成カウント対象。

666でCPUにあがられて敗北した場合も、プレイヤーがRollでTripleを成立させているためMT育成には含める。

Triple累計6回でMachine Tier育成。

## 10. 設計上の特徴

黄台と同じAタイプ系統だが、配当構造を差別化する。

**黄台：** Tripleの数字そのものが配当額へ直結。

**花札台：** Tripleを花札役へ変換。

特に、

- 555 = 五光・最高役
- 666 = CPUあがり・敗北

とすることで、「大きい数字ほど強い」という単純な序列を崩す。

555成立時は最高の期待。

666成立時は敗北。

花札らしい役名と、Triple成立時の期待と恐怖をゲームの中心とする。
