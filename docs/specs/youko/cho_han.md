# TierSlot 丁半 — 日本・ヨウコ枠

## 1. 基本コンセプト

日本の伝統的な賭博「丁半」をベースとした3Roll完結型ゲーム。

本来の丁半が持つ「丁か、半か」というシンプルな二択勝負を維持しつつ、

宣言 → 第一骰子開示 → 第二骰子開示 → 決着

という3Roll構成によって、開示を待つ緊張感を作る。

特殊役による派手な勝敗演出は追加せず、丁半そのものの決着感を重視する。

## 2. 1ゲームの構成

1ゲームは固定3Roll。

### 1Roll目

丁または半を決定する。

**AUTO OFF：** プレイヤーが手動選択。
- 十字キー左：丁
- 十字キー右：半

**AUTO ON：** 1Roll目のDestiny Rollによって自動決定。
- 奇数：半
- 偶数：丁

丁／半決定後、画面中央に大きく「丁！！」または「半！！」を約1秒間表示して消す。

1Roll目も通常のRollとして扱い、BT判定・Triple判定の対象とする。

## 3. 2Roll目

丁半判定に使用する1個目の骰子を開示。

例：5

この時点では勝敗を確定しない。

2Roll目もBT判定・Triple判定の対象。

## 4. 3Roll目

丁半判定に使用する2個目の骰子を開示。

2個の骰子の合計によって勝敗を判定する。

- 合計が偶数：丁
- 合計が奇数：半

3Roll目の停止と同時に勝敗結果を表示する。

3Roll目もBT判定・Triple判定の対象。

## 5. 勝敗表示

3Roll目が停止した瞬間に表示。

**日本語版の例：**
- 五二の丁！！ 勝ち
- 六三の半！！ 負け

**英語版：** 日本独自の丁半文化を残すため、日本語読みをローマ字化して使用する。

例：
- GORONINO CHO!! WIN
- ROKUSANNO HAN!! LOSE

英語表記では、丁 = CHO、半 = HANを基本表記とする。

## 6. 特殊勝敗演出

Tripleや123／456による特殊な勝敗演出は設けない。

勝敗演出の主役はあくまで丁／半の結果とする。

123／456やTripleは内部システム上のBT・MT育成として処理する。

## 7. BT

初期値：BT1

各Rollで123または456（順不同）成立時、BT +1。

1ゲームは3Rollあるため、1ゲーム中最大BT +3まで上昇可能。

1Roll目・2Roll目・3Roll目すべてBT判定対象。

## 8. BT持ち越し

**勝利：** 現在のBTをそのまま次ゲームへ持ち越す。

**敗北：** 勝敗処理終了後、BT1へリセット。

## 9. 3Roll目のBT処理順

3Roll目で123／456が成立した場合、

1. まずBT +1を処理する。
2. その後、上昇後のBTを使用して最終配当を計算する。
3. 最後に勝敗処理を行う。

敗北していた場合のみ、次ゲーム開始時BT1へ戻す。

## 10. Machine Tier育成

1Roll目・2Roll目・3Roll目すべてで、プレイヤーが出したTriple（111～666）をMT育成カウント対象とする。

1ゲーム中に複数回Tripleが成立した場合、すべてカウントする。

丁半の勝敗とは独立して処理する。

## 11. BET

BETはMachine Tierによって順次解放。

| MT | 選択可能BET（Coin） |
|---|---|
| MT0 | 100 |
| MT1 | 100 |
| MT2 | 100 / 500 |
| MT3 | 100 / 500 / 1,000 |
| MT4 | 100 / 500 / 1,000 / 3,000 |
| MT5 | 100 / 500 / 1,000 / 3,000 / 5,000 |
| MT6 | 100 / 500 / 1,000 / 3,000 / 5,000 / 10,000 |

## 12. 基本配当

丁半的中時は基本1:1。

そのため補正前の払い出しはBET × 2とする。

敗北時の払い出しは0 Coin。

## 13. 丁半専用配当補正

補正率：

`0.895 + MT × 0.025 + BT × 0.005`

最終払い出し：

`floor(BET × 2 × 補正率)`

つまり、

`floor(BET × 2 × (0.895 + MT × 0.025 + BT × 0.005))`

小数点以下は切り捨て。

## 16. 設計思想

丁半はルールそのものを複雑化しない。

ゲーム性の中心は、「丁か半か」という50:50の勝負と、1個目の骰子が開いた状態で2個目を待つ緊張感に置く。

MTは勝率を変更せず、払い出し倍率のみを成長させる。

BTは勝ち続ける限り維持できるが、一度負ければBT1へ戻る。

これにより、「勝って育ったBTを抱えたまま、もう一勝負する」という連戦の動機を作る。
