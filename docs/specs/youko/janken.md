# TierSlot じゃんけん — 日本・ヨウコ枠

## 基本コンセプト

じゃんけんを利用したダブルアップ・チキンレース台。

ルールそのものは非常に単純だが、勝利するたびに払い出しが倍増する。

勝利後に、
- TAKEして利益を確定する
- CONTINUEしてさらに倍を狙う

をプレイヤーが選択する。

「もう1戦行くか、今やめるか」を最も直接的に表現する台とする。

## BET

- 100 Coin
- 500 Coin
- 1,000 Coin
- 3,000 Coin
- 5,000 Coin
- 10,000 Coin

## BT

使用しない。

## じゃんけん判定

DR3を使用。

DR3は3D6の216通りを均等に3分割し、1～3を各1/3で出力する。

- DR3 = 1：グー
- DR3 = 2：チョキ
- DR3 = 3：パー

プレイヤーとCPUはそれぞれ独立してDR3を行う。

## 初戦

BETを支払ってじゃんけん開始。

初戦勝利 → BET ×2の払い出し権を獲得。

例：BET 100 → 初戦勝利 → 200 Coin

## 勝利

現在の払い出し額を×2する。

勝利後、TAKEまたはCONTINUEを選択する。

## TAKE

現在の払い出し額を受け取り、ゲーム終了。

## CONTINUE

現在の払い出し額すべてを賭けて次戦へ進む。

- 勝利 → 現在額×2
- 敗北 → 0 Coin
- あいこ → 現在額維持

## あいこ

払い出し額および倍率を維持。

そのまま再戦する。

連勝数には加算しない。

## 敗北

払い出し0 Coin。

その時点でゲーム終了。

## 最大連勝数

最大連勝数 = MT + 4

| MT | 最大連勝数 | 最大倍率 |
|---|---:|---:|
| MT0 | 4連勝 | ×16 |
| MT1 | 5連勝 | ×32 |
| MT2 | 6連勝 | ×64 |
| MT3 | 7連勝 | ×128 |
| MT4 | 8連勝 | ×256 |
| MT5 | 9連勝 | ×512 |
| MT6 | 10連勝 | ×1024 |

最大連勝数へ到達した場合は強制TAKE。

## RTP基本思想

プレイヤーとCPUのグー・チョキ・パーは各1/3。

1戦あたり、
- 勝利：1/3
- 敗北：1/3
- あいこ：1/3

あいこは現在額を維持して再戦するため、最終的に決着する場合、
- 勝利：50%
- 敗北：50%

となる。

勝利時×2、敗北時×0なので、ダブルアップ部分の理論期待値は100%。

最大連勝数による強制TAKEを設けても、基本的な理論期待値100%は維持される。

## MTの役割

MTによって勝率や配当倍率そのものを補正しない。

MTが上昇するほど、挑戦可能な最大連勝数が増加する。

つまりMTは、

「期待値を上げる成長」

ではなく、

「より大きな一撃へ挑戦できる成長」

として機能する。

## 台の役割

ヨウコ6台の中では、

- ダブルアップ
- 連勝
- チキンレース
- 欲張るか、確定するか

を担当する。

ルールは最も単純だが、最大10連勝・1024倍というヨウコ店最大級の一撃を狙える破格の台とする。
