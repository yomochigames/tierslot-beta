# TierSlot 双六 — 日本・ヨウコ枠

## 基本コンセプト

32マスの環状盤面をDR6で進み、1周してSTART地点を通過するとMAIN BONUSへ突入する。

道中のSUB BONUSで、その周回のMAIN BONUS報酬タイプを事前に抽選する。

「盤面を一周する双六」＋「途中でゴール報酬を仕込む」という構造。

## 盤面

全32マス。

- 左下：START兼MAIN BONUSエリア
- 左上：ピタリ停止でSTARTへ戻る
- 右上：SUB BONUSエリア
- 右下：ピタリ停止で右上へ戻る
- 左下START直前：3連関門を配置

## 通常移動

通常RollごとにBETを消費。

3D6をRollし、DR6で1〜6を算出。

DR6の値だけ盤面を進む。

## START / MAIN BONUS

左下の隅がSTART兼MAIN BONUSエリア。

ゲーム開始時はここからスタートする。

盤面を1周し、左下STARTを通過した時点でMAIN BONUSへ突入。

ピタリ停止する必要はない。

## 左上特殊マス

左上の隅へピタリ停止した場合、STARTへワープする。

ただし、左上からのワープによるSTART到着ではMAIN BONUSは発生しない。

## SUB BONUS

右上の隅がSUB BONUSエリア。

右上を通過すると、無料のボーナスRollを1回行う。

DR6によって、今回のMAIN BONUSの報酬TYPEを決定する。

TYPE1〜TYPE6は各1/6。

## 右下特殊マス

右下の隅へピタリ停止した場合、右上へワープする。

右上へ戻った後は盤面進行を継続する。

## ゴール前3連関門

START / MAIN BONUS直前の3マスを特殊関門とする。

各関門ではDR6を行い、

- 4以上 → 関門突破
- 1〜3 → 関門失敗

失敗時のペナルティは以下。

- 第1関門 → 3マス戻る
- 第2関門 → 2マス戻る
- 第3関門 → 1マス戻る

3つの関門を突破してSTARTを通過するとMAIN BONUSへ突入する。

## MAIN BONUS

SUB BONUSで決定されたTYPEに対応する配当テーブルを使用。

無料でDR6を1回行い、DR6の結果によって基礎配当を決定する。

## MAIN BONUS配当

100BET基準。

| TYPE | 特徴 | DR1 | DR2 | DR3 | DR4 | DR5 | DR6 | 期待値 |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| TYPE1 | 安定型 | 600 | 750 | 900 | 1,050 | 1,350 | 1,650 | 1,050 Coin |
| TYPE2 | 堅実型 | 0 | 700 | 900 | 1,200 | 1,600 | 2,200 | 1,100 Coin |
| TYPE3 | 標準型 | 0 | 0 | 900 | 1,200 | 1,600 | 3,050 | 1,125 Coin |
| TYPE4 | 勝負型 | 0 | 0 | 0 | 1,300 | 1,900 | 3,700 | 1,150 Coin |
| TYPE5 | 大勝負型 | 0 | 0 | 0 | 0 | 2,500 | 4,550 | 1,175 Coin |
| TYPE6 | 一撃型 | 200 | 200 | 200 | 200 | 200 | 6,500 | 1,250 Coin |

## TYPE設計思想

TYPEが高いほど配当が荒くなる。

同時に、TYPEが高いほど期待値も少し高くする。

- TYPE1 → 安定
- TYPE2 → 堅実
- TYPE3 → 標準
- TYPE4 → 勝負
- TYPE5 → 大勝負
- TYPE6 → 一撃

TYPE6は完全ハズレにはせず、DR1〜5でも最低保証200 Coin。

DR6成立時のみ6,500 Coin。

## SUB BONUS全体期待値

TYPE1〜6は各1/6。

100BET基準で、MAIN BONUS基礎期待値 約1,141.7 Coin。

## BET

6段階。

- 100 Coin
- 500 Coin
- 1,000 Coin
- 3,000 Coin
- 5,000 Coin
- 10,000 Coin

## BET倍率

MAIN BONUS配当表は100BET基準。

BET額に応じて比例拡大する。

例：TYPE6、DR6 = 6,500 Coin

| BET | 配当 |
|---:|---:|
| 100 | 6,500 |
| 500 | 32,500 |
| 1,000 | 65,000 |
| 3,000 | 195,000 |
| 5,000 | 325,000 |
| 10,000 | 650,000 |

## BET開放

BET帯はMachine Tierに応じて順次開放する。

## BT

BT初期値：1

通常移動Rollで123または456が順不同で成立した場合、BT +1。

MAIN BONUS払い出し終了後、BT = 1へリセット。

## MT育成

通常移動RollでプレイヤーTriple成立時のみMachine Tier育成カウント対象。

111 / 222 / 333 / 444 / 555 / 666

すべて対象。

## 無料BONUS Roll

以下のRollはBET無料。

- SUB BONUS
- MAIN BONUS

これらの無料RollではBT育成なし、MT育成なしとする。

## 配当補正

最終配当補正率：

`0.94 + MT × 0.027 + BT × 0.005`

## 最終払い出し

最終払い出し = 基礎配当 × BET倍率 × 配当補正率

小数点以下切り捨て。

## シミュレーション暫定結果

32マス盤面と特殊マスを含めたシミュレーションでは、

MAIN BONUS到達までの通常Roll数：

- 平均：約12.03 Roll
- 中央値：11 Roll

100BET時の平均投入額目安：約1,203 Coin。

## この台の特徴

- DR6をそのまま双六の移動量として使用
- 32マス環状盤面
- 右上でゴール報酬の性格を先に抽選
- 左下でMAIN BONUS
- 左上、右下のワープ
- ゴール前3連関門
- TYPE1〜6で安定型から一撃型まで変化
- BTは1周のあいだ蓄積
- MTは長期的な配当補正
- 盤面そのものの移動確率はMTで変更しない
