# CHAIN（新・連続成功型）【基本ルール正式コミット】

> 2026-10-08 引き継ぎ書に基づく。旧AT型CHAINとは別仕様。MT補正倍率は過去提案値であり、RTPは要再検証。

## 基本ルール
- DR6を**2回**振り、合計7ならCHAIN成功、それ以外は終了。
- 成功確率：**6/36＝1/6**。
- 1CHAIN目：報酬なし。
- 2CHAIN目：報酬発生。
- 3CHAIN目以降：成功のたび追加報酬。
- 失敗時、それまで蓄積したBONUSを**全額獲得**してCHAINをリセット。
- **CHAIN上限なし**。
- DR6のみ。Triple／Pair／123・456特殊効果なし。BTなし。

## BET
- **DR6を1回振るごとにBET消費**。
- 1回のCHAIN判定に2Roll必要。
