# TEN【基本ルール正式コミット】

> 2026-10-08 引き継ぎ書に基づく。**倍率は最終未確定**。

## 基本ルール
- DR6を1回ずつ振り、出目をTOTALに加算。
- TOTALが**10未満**：継続。
- TOTALが**ちょうど10**：TEN成功、報酬獲得。
- TOTALが**10超**：BUST、報酬なし。
- TEN成功・BUST時にTOTALを0に戻し、次Rollから新たに挑戦。
- **3Roll制限なし**。
- **1RollごとにBET消費**。
- DR6のみ使用。Triple・Pair・123/456などの特殊役なし。
- BTなし。
