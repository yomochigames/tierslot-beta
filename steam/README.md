# TierSlot — Steam / Godot

Steam向けTierSlotの仕様・設計資料をまとめる作業領域です。

**注意:** このディレクトリは仕様書用の仮置き場です。Godotプロジェクト本体はまだ配置していません。既存のリポジトリ直下のWeb版（game.js / index.html / style.css）は変更しません。

- `docs/common/`: 全36台共通のルール
- `docs/machines/`: 店主別・各6台の仕様書
- `docs/adventure/`: 冒険モード
- `docs/ui/`: UI・筐体・操作
- `docs/development/`: 進捗・未確定事項

仕様の状態（確定・仮・未定）を明示して管理します。
